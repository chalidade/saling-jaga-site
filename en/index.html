FAQ

Still unsure?

All questions

Really no internet or credit?

Really. The phone can even have no SIM card. Only Wi‑Fi and Location need to be on. Internet is only used to install the app and, if you like, to download the map around you.

Do other people need to install it too?

Yes, every phone you want to connect needs Saling Jaga. So install it now and bring in your family, neighbours or group. Laptops and iPhones can join through a browser, opened from an Android phone running Saling Jaga.

How far does it reach?

About 50–100 m in the open, shorter indoors. When a group spreads out, a phone in the middle can act as a bridge and pass messages on. See how to extend the range.

Are my messages safe?

There is no server and no account. Messages move directly between phones and are encrypted. See security and permissions.

Is it free?

Free for the public, with no ads. For SAR teams, command posts or institutions that need training and customisation, book a demo.
